# Phase 3 — Wave 2: AJAX Scan & Scanner Listener

## Goal

Convert the Prepare page from full-page-reload scan flow to a seamless AJAX experience. Create `scanner.js` with a barcode scanner keystroke listener (rapid-input detection), AJAX `fetch()` to `ScanAjax`, real-time DOM updates (insert package row, update progress bar, update counter), and audio feedback. Update `Prepare.cshtml` to use `PrepareViewModel` and reference `scanner.js`.

## Tasks

<task id="03-02-01">
<objective>Create scanner.js with barcode scanner keystroke listener, AJAX scan, DOM updates, and audio feedback (D-01, D-02, D-03, D-04)</objective>
<read_first>
- MothersonBoxManagement/Controllers/BoxController.cs (the ScanAjax action — JSON response shape: { success, message, currentQuantity, expectedQuantity, status, package: { barcode, scannedAt, scannedBy } })
- MothersonBoxManagement/Views/Shared/_Layout.cshtml (CSRF meta tag: <meta name="RequestVerificationToken" content="...">)
- MothersonBoxManagement/Views/Box/Prepare.cshtml (full file — current form structure, element IDs, progress bar markup, package table markup)
</read_first>
<action>
1. Create new file `MothersonBoxManagement/wwwroot/js/scanner.js`.
2. Implement barcode scanner keystroke detection:
   - Listen to `keydown` events on `document`.
   - Buffer keystrokes with timestamps. If characters arrive faster than 50ms apart, treat as scanner input (USB wedge scanners type at ~10ms/char, D-03).
   - On `Enter` key (`event.key === "Enter"`), if buffer length >= 3 and was filled rapidly, call `submitScan(buffer)` and clear the buffer.
   - If time between keystrokes exceeds 100ms, reset the buffer (user is typing manually, not scanner).
3. Implement `submitScan(barcode)` function:
   - Read CSRF token from `document.querySelector('meta[name="RequestVerificationToken"]').content`.
   - Read `boxId` from `document.getElementById('scanBoxId').value`.
   - Read `boxBarcode` from `document.getElementById('scanBoxBarcode').value`.
   - Build `FormData` with `boxId`, `boxBarcode`, `barcode`.
   - Call `fetch('/Box/ScanAjax', { method: 'POST', headers: { 'X-CSRF-TOKEN': csrfToken }, body: formData })`.
   - Parse JSON response.
   - On success: call `addPackageRow(data.package)`, `updateProgressBar(data.currentQuantity, data.expectedQuantity)`, `showFeedback(true, data.message)`, `playBeep(true)`.
   - On failure: call `showFeedback(false, data.message)`, `playBeep(false)`.
   - If `data.status === "Completed"`: call `disableScanInput()` (D-04).
   - Always re-focus and clear the manual scan input field (D-01).
4. Implement `addPackageRow(pkg)`:
   - Prepend a `<tr>` to `#packageTableBody` with `<td><code>${pkg.barcode}</code></td><td>${pkg.scannedBy}</td><td>${pkg.scannedAt}</td>`.
   - Update the package count header text.
   - If no-packages placeholder `<p class="text-muted">` exists, remove it.
5. Implement `updateProgressBar(current, expected)`:
   - Calculate percent: `Math.round((current / expected) * 100)`.
   - Set `#progressBarFill` style width and text content.
   - Add CSS class `bg-success` if percent >= 100, else `bg-primary`.
   - Add `pulse-success` animation class, remove after 1500ms via `setTimeout` (D-02).
6. Implement `showFeedback(isSuccess, message)`:
   - Insert or update a Bootstrap alert div `#scanFeedback` above the form (D-02).
   - Use `alert-success` or `alert-danger` class.
   - Auto-dismiss after 5 seconds via `setTimeout`.
7. Implement `playBeep(isSuccess)`:
   - Use `AudioContext` / `OscillatorNode` to generate a short beep.
   - Success: 800Hz, 150ms. Error: 300Hz, 300ms.
8. Implement `disableScanInput()`:
   - Set scan input `disabled = true` and placeholder to `"Box complétée"` (D-04).
   - Set scan button `disabled = true`.
9. Also wire the manual scan form's `submit` event to `preventDefault()` and call `submitScan(inputValue)` instead — so both manual typing+Enter and scanner input use AJAX.
</action>
