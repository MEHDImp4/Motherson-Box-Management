</objective>

## Task 2: Implement Box Level Exceptions
<read_first>
- `MothersonBoxManagement/Services/BoxService.cs`
</read_first>
<action>
1. Implement `ModifyExpectedQuantityAsync`: Update `ExpectedQuantity`, `UpdatedAt`, `LastModifiedByUserId`. Re-evaluate box status (if `CurrentQuantity` >= `newQuantity`, set to Completed).
2. Implement `CancelBoxAsync`: Set `Status` to `Cancelled`, update user/timestamps.
3. Implement `ForceCloseBoxAsync`: Set `Status` to `CompletedWithException`, update user/timestamps.
4. Implement `BlockBoxAsync`: Set `Status` to `Blocked`, update user/timestamps.
5. Implement `UnblockBoxAsync`: Revert `Status` to `Open` (or `Completed` if full), update user/timestamps.
</action>

## Task 3: Implement Package Level Exceptions
<read_first>
- `MothersonBoxManagement/Services/BoxService.cs`
</read_first>
<action>
1. Implement `BlockPackageAsync` & `UnblockPackageAsync`: Find `BoxPackage`, set `IsBlocked` and `BlockReason`. 
2. Implement `RetraitPackageAsync`: Find `BoxPackage`, remove it from `_context.BoxPackages`. Decrement `Box.CurrentQuantity`. Re-evaluate box status. Use a transaction.
3. Implement `TransferPackageAsync`: Find `BoxPackage`. Validate `targetBoxId`. Update `BoxPackage.BoxId` to `targetBoxId`. Decrement source box `CurrentQuantity`, increment target box `CurrentQuantity`. Re-evaluate both boxes' statuses. Use a transaction.
</action>
<acceptance_criteria>
- Package-level methods use EF Core transactions `BeginTransactionAsync`.
- `TransferPackageAsync` correctly adjusts quantities of both source and destination boxes.
- `RetraitPackageAsync` successfully deletes the package record.
</acceptance_criteria>
