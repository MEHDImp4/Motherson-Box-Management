<threat_model>
### STRIDE Threat Model

| Threat Category | Description | Boundary / Target | Mitigation | Verification |
|---|---|---|---|---|
| **Spoofing (S)** | An unauthorized user or external system attempts to impersonate an Operator or Supervisor to invoke operations. | Authentication Cookie & Session Boundary | HTTP-only Lax security cookies, explicit authentication checks via ASP.NET Core cookie authorization. | Verified in `AccountControllerTests` and `SecurityAuditTests`. |
| **Tampering (T)** | Malicious payloads modify input fields (dimensions, barcodes) to bypass structural limits. | Controller Input Model Binding | Strong ModelState validations requiring positive dimensions and minimum lengths for barcodes. | Verified in `SecurityAuditTests.InputValidation_RejectsInvalidBoxDimensions`. |
| **Repudiation (R)** | A supervisor triggers an exceptional action (force-close, block) and denies performing it. | Box Exception Operations & Logging | Mandatory exception reasons stored in the box table, plus an unalterable `BoxAuditLogs` trail. | Verified in `E2ELifecycleTests` checking the details of `BoxAuditLogs`. |
| **Information Disclosure (I)** | Unhandled database exceptions leak connection strings, SQL commands, or path variables to the client. | HTTP Response Payload | Global `UseExceptionHandler` pipeline middleware mapping to `/Home/Error` in non-development mode. | Verified in `SecurityAuditTests.GlobalExceptionHandler_SuppressesDetails`. |
| **Denial of Service (D)** | High-frequency concurrent scans block the database row, leading to locked transactions or deadlocks. | Database updates / `ScanPackageAsync` | Optimistic concurrency token (`RowVersion` column) + 3-attempt reload-and-retry execution loop. | Verified in `ConcurrencyTests.ScanPackage_RetryOnConcurrencyConflict_Succeeds`. |
| **Elevation of Privilege (E)** | An Operator calls Supervisor endpoints to transfer packages, unblock boxes, or force-close them. | Authorization Filter Boundary | Role-based policies (`[Authorize(Roles = "Supervisor,Administrator")]`) blocking unauthorized controllers/actions. | Verified in `SecurityAuditTests.Operator_CannotAccess_SupervisorEndpoints`. |
</threat_model>
