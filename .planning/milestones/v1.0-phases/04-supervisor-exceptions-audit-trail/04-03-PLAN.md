# Phase 4 - Plan 3: UI Updates & Audit Log View

<objective>
Expose the supervisor exception methods via the UI on the Box Details page, and create a dedicated Audit Log viewer page.
</objective>

<tasks>

## Task 1: Box Details Exception Buttons
<read_first>
- `MothersonBoxManagement/Views/Box/Details.cshtml`
- `MothersonBoxManagement/Controllers/BoxController.cs`
</read_first>
<action>
1. In `BoxController.cs`, add POST actions for `CancelBox`, `ForceCloseBox`, `ModifyExpectedQuantity`, `BlockBox`, `UnblockBox`, `TransferPackage`, `RetraitPackage`, `BlockPackage`, `UnblockPackage`.
2. Secure all these new actions with `[Authorize(Roles = "Supervisor,Admin")]`.
3. In `Details.cshtml`, wrap the exception buttons in an `if (User.IsInRole("Supervisor") || User.IsInRole("Admin"))` block.
4. Add the buttons to the box header (Cancel, Force Close, Block, Modify Quantity) and to each package row (Transfer, Remove package, Block).
5. Implement inline forms or small modals (e.g., Bootstrap modal) to capture the mandatory `Reason` string (and `destinationBoxId` for transfers). For Transfer, include a dropdown of Open boxes.
</action>
<acceptance_criteria>
- Endpoints enforce Role-based authorization.
- Buttons are only visible to authorized roles.
- Actions correctly trigger `BoxService` methods and redirect back to `Details` with a TempData success/error message.
</acceptance_criteria>

## Task 2: Audit Controller and View
<read_first>
- `MothersonBoxManagement/Controllers/AuditController.cs` (Create new)
- `MothersonBoxManagement/Views/Audit/Index.cshtml` (Create new)
</read_first>
<action>
1. Create `AuditController` with an `Index` action secured by `[Authorize(Roles = "Supervisor,Admin")]`.
2. The `Index` action should fetch `BoxAuditLog` records from the DbContext, ordered by `Timestamp` descending. Include basic filtering (e.g., by BoxId or Date) and pagination.
3. Create the `Index.cshtml` view to display a table of logs (Timestamp, Action Type, User, Workstation, BoxId, Details).
4. Render the `DetailsJson` in a readable format (e.g., inside a `<pre>` tag).
</action>
<acceptance_criteria>
- `/Audit/Index` loads a paginated list of all audit logs.
- The UI is read-only.
- The details JSON is visible and readable.
</acceptance_criteria>

## Task 3: Navigation Update
<read_first>
- `MothersonBoxManagement/Views/Shared/_Layout.cshtml`
</read_first>
<action>

<acceptance_criteria>
