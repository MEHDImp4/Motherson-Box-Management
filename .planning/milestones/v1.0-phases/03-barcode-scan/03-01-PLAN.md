# Phase 3 — Wave 1: Backend Hardening

## Goal

Harden the existing `ScanPackageAsync` flow with SQL transactions, optimistic concurrency retry, `DbUpdateException` catch for unique-index violations, barcode trimming, and audit logging. Add CSRF anti-forgery protection globally, create `PrepareViewModel`, and expose a new `ScanAjax` JSON endpoint for Wave 2 frontend consumption.
